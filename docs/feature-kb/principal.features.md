### Admin Panel

- Key: `nav:/admin`
- Confidence: high
- Documentation from: help + extracted

```text
Admin Panel
Where: Left menu, Admin Panel.
What it is: Set up your school's classes and connect people to them: create classes, put students in classes and assign teachers as primary or subject teachers.
How to use it: (1) Open the Classes tab and press New Class. (2) Type the Class Name, for example Class 5, Nursery or LKG. This is required; nothing is saved without it. (3) Type the Section, for example A, B or C. If you leave it empty the section is set to A. (4) Press Create Class.
Good to know: You see Class created and the class appears in the list. Until you create one the list says No classes created yet.
If something goes wrong: Assigning a subject teacher is refused. - Type the Subject, or change the Role to Primary Teacher. Assigning a student is refused. - That student is already assigned to that class. Choose a different class if that was a mistake. The Assign button is greyed out. - Choose a Class and a Student (or a Class and a Teacher) first.
```

```text
Attendance
Where: Left menu, Attendance.
What it is: Mark and review student attendance, and also staff attendance for teachers, drivers and bus attendants. Admins also get Attendance Risk. The tabs you see depend on your role.
How to use it: (1) Open the Student Attendance tab and choose the class from Select class. (2) Choose the date, and the period if a Period box appears. Good to know: You see Attendance saved, or a count of how many students were saved and how many are still unmarked.

You cannot see the Attendance Risk tab. - It is shown to teachers and admins only, so principals do not see it.
