### Attendance

- Key: `nav:/attendance`
- Confidence: high
- Documentation from: help + extracted

```text
Attendance
Where: Left menu, Attendance.
What it is: Mark attendance for a class, look back at saved records, and see your own attendance on My Attendance. Teachers also get an Attendance Risk tab.
How to use it: (1) Open the Student Attendance tab. (2) Choose the class from Select class. Each choice shows the class name and its section. (3) Choose the date in the date box. (4) If a Period box appears, choose the period (Period 1, Period 2 and so on). It only appears when your school marks attendance by period. (5) Wait for the student list to load. Each student shows their name and roll number. (6) Set a status for each student: Present, Absent, Late, Half Day or Excused. To save time press Mark all present first and then change the exceptions. (7) Check the counter showing how many students you have marked out of the total. (8) Press Save Attendance.
Good to know: You see Attendance saved. If you left students unmarked it says, for example, that attendance was saved for some of the students and that some are still unmarked. Unmarked students are skipped, never assumed present. Parents of the students you marked receive an Attendance Update notification. If you save the same class and date again, the existing records are updated.
If something goes wrong: The student list is empty. - That class and section has no active students. Check that you picked the right class, otherwise ask your school admin. Some students were not saved. - A student you did not mark is skipped on purpose. Mark the remaining students and press Save Attendance again. Saving shows an error. - The message after Error says what failed. Press Save Attendance again and, if it keeps failing, give the message to your school admin.
```
